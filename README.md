# midcode for Homebrew

```bash
brew install --cask agusdellaquila/midcode/midcode
```

[midcode](https://midcode.app) is a visual editor for the sites you build in code, for macOS. The app updates itself; `brew upgrade --cask midcode` works too.

Issues: [agusdellaquila/midcode](https://github.com/agusdellaquila/midcode/issues).
